# SICK TiM LiDAR ハイブリッド入力計画

作成日: 2026-08-21
状態: 計画・調査段階（TiM実機の型番確認とスキャン実測が未完了）

## 目的

姿勢推定の人物検出が不安定な環境で、左右移動と在席判定をSICK TiM系2D LiDARで補強する。ジャンプは上下方向の情報が必要なため、当面は既存カメラの姿勢推定を使う。

## 想定する構成

```text
SICK TiM（腰〜胸の高さ・水平走査）
  ├─ 在席判定
  └─ 左右位置 → ゲーム入力

カメラ（既存）
  └─ ジャンプ判定
```

画面の対面、廊下を挟んだ側から画面と人物を見る配置を第一候補とする。人物を正面から捉えられ、床面を直接走査しにくい。画面は固定背景として無人時のスキャンを保存し、人物クラスタを分離する。

## 通信方針

TiM側はEthernet接続を基本とする。親機までケーブルを引ける場合は有線を優先する。配線が難しい場合は、TiMのEthernetをセンサー側のWi-Fiブリッジへ接続し、親機とは既存無線で通信する。

```text
TiM ─ Ethernet ─ Wi-Fiブリッジ ))))) 親機
```

LEDフレーム配信用の専用ネットワークへWi-Fiブリッジを無断で混在させない。センサー用の経路とアドレスは、実機・会場配線を確認してから確定する。

## 実装手順

1. 本体ラベルからTiMの正確な型番、ファームウェア、接続方式を記録する。
2. ゲームから独立したプローブで、スキャンデータを取得・保存する。
3. 無人、中央、左、右、通行人、ジャンプの各状態を収録する。
4. 人物クラスタの在席率、左右位置の分離、鏡面床による外れ値を評価する。
5. 無線を使う場合は、パケット欠損、遅延、再接続時間を実測する。
6. 合格した場合だけ、TiMの左右位置をゲーム入力へ接続する。
7. カメラはジャンプ判定に限定し、TiM欠損時は短時間の位置保持または安全側の入力へ切り替える。

## 合否基準

- 無人時に在席と誤判定しない。
- 中央・左・右の位置分布が実測で分離する。
- Wi-Fi使用時も、ゲーム入力の停止・飛びを再現しない。
- TiM単独でジャンプ判定を成立条件にしない。
- 実機で取得したログを再生して同じ判定になる。

## リスク

- TiMは単一走査面の2D LiDARなので、上下方向のジャンプを単独で確実に識別できない。
- 鏡面床・ガラス・光沢面はレーザー反射の外れ値を生む可能性がある。
- Wi-Fiは帯域よりも瞬断・遅延・再接続がリスクになる。
- 型番により走査範囲、角度分解能、出力方式、通信設定が異なる。
