# oyaki 親機スナップショット

取得日: 2026-08-21
取得元: `th1@169.254.10.1:/home/th1/hackathon-2026`

このディレクトリは、親機上に存在したGit管理外の実機用ファイルを保全するためのスナップショットである。現行ブランチの正本と内容が異なるゲームソースは、上書きせずここへ保存する。

## 内容

- `host/`: 親機で実行されていた現行ゲームソースとの差分および実機用補助ツール
- `runtime/`: 実行コマンド、プロセス状態、取得時のハッシュ
- `backups/`: 親機に残っていたバックアップ履歴（Pythonキャッシュ・仮想環境は除外）

姿勢推定モデル本体は、再現性確保のため通常の `host/models/` に保存する。

Pi本体へのSSHは開発機・親機経由とも認証鍵が一致せず読み取りできなかった。そのため、Pi側については本リポジトリの `pi-client/` ソースと、親機から確認できた接続状態のみを正本とする。
